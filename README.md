## 🐣 这是什么

养宠物的人都有过这种时刻：想不起来今天到底遛了几次、上次喂药是什么时候、便便正不正常。

**GoGoDiary 就是为此做的。** 它是一本给宠物用的"流水账"——几点遛了狗、几点吃了饭、几点拉了屎，戳一下按钮就记上，回头一看清清楚楚。

它很**轻**：没有账号、不用注册、不联网、不上传。你的日记就安安静静躺在你自己的手机里。🔒

## 🎁 它都能干啥

### ⚡ 一键速记
- 点一下大按钮 = 记一条，自动带上当前时间，不弹窗、不打断
- 最常用的 **8 个按钮**直接摆在前面，用不到的收进第 9 格「**更多**」，点一下就展开
- 想清爽一点？还能把不常用的按钮**藏起来**（每只宠物各藏各的）

### 🐶 每只宠物，各有一套按钮
狗有「遛狗」、猫有「外出」、鸟有「遛鸟」、鱼有「换水」——**同一个动作，说各自的词**。
鱼不会出现「摸摸」，乌龟也不会出现「遛弯」，每条按钮都贴合它的主人。🐢

### ⏱️ 出门就计时
遛狗、猫出门、鸟出笼、兔鼠放风……点「开始」，走表；回来点「结束」，**自动算好时长**。
中途锁屏、切走、甚至把 App 关掉，**计时照样在跑**，不怕白遛。🕒

### 📸 顺手拍张照
每条记录都能加照片（便便性状、皮肤状况、今天的新造型…）。图片会**自动压缩**后存在本地，不占太多空间，导出备份时也一起打包。

### 📊 回头看看统计
- 最近 7 天每天记了多少，一根根小柱子一眼看完 📊
- 这周总共遛了多久、最近一次出门多长时间
- 「距上次遛狗已经 3 小时 20 分」——再也不用凭感觉

### 🐱 多只宠物随便加
猫猫狗狗再加上鱼缸里的，顶部一键切换，各记各的。

### 💾 数据全在本地 + 随时备份
- **100% 存在你自己的浏览器里**，没有服务器、没有账号、不联网
- 设置页可以**导出成一个 JSON 文件**（连照片一起打包），换手机时导入就能完整恢复
- 也支持「合并导入」（同一条不重复）和「覆盖导入」

### 📱 装到手机，就是 App
支持 PWA：手机浏览器打开后「添加到主屏幕」，就有独立图标、全屏打开、**断网也能用**。

## 📱 30 秒上手

1. 手机浏览器打开 **https://xinchenxia01.github.io/GoGoDiary/**
2. iPhone：Safari 分享键 →「**添加到主屏幕**」；安卓：Chrome 菜单 →「**安装应用**」
3. 打开后先「设置」里加一只宠物（选物种 🐕🐈🐇🐦🐠🐹🦎），回到首页，戳按钮开记！

> 💡 换了手机或清了浏览器缓存会让本地数据消失，记得偶尔去「设置」里**导出一次备份**。

## 🔒 关于隐私

- ❌ 没有服务器，❌ 没有账号，❌ 不联网，❌ 没有统计埋点
- ✅ 所有记录和照片只存在**你打开它的那台设备**上（浏览器的 localStorage + IndexedDB）
- ✅ 想搬去新手机？导出 JSON → 新手机导入，搞定

## 🛠️ 想自己跑起来

```bash
npm install      # 装依赖
npm run dev      # 本地开发（手机和电脑同一 WiFi 时可用局域网 IP 访问）
npm run build    # 打包到 dist/
npm run preview  # 预览打包结果
npm test         # 跑测试（node --test）
```

**技术栈**：Vite 5 · React 18 · Tailwind CSS 3 · PWA（Service Worker 离线）
**运行时零第三方依赖**（没引 UI 库 / 路由 / 状态库 / 图表库），全程原生 API。

## 📂 项目结构

```
pet-diary/
├─ src/
│  ├─ App.jsx                 # 单页容器：换宠物 / 日期 / 速记 / 时间轴 / 统计 / 设置
│  ├─ components/             # 界面组件（速记区、时间轴、编辑面板、统计、设置…）
│  └─ lib/
│     ├─ eventTypes.js        # 事件体系：基础池 + 物种预设 + 名称覆盖 + 隐藏 + 自定义
│     ├─ storage.js           # localStorage 唯一出入口（含导出/导入校验、脏数据兜底）
│     ├─ photoStore.js        # 照片存 IndexedDB + 图片压缩 + base64 互转
│     └─ format.js            # 本地时区时间 / 时长格式化
├─ public/                    # manifest.webmanifest · sw.js · 应用图标
├─ tests/                     # 测试用例（含物种矩阵、计时、照片、迁移兼容）
└─ docs/                      # 产品与设计文档
```
